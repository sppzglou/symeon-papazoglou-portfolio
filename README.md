# Symeon Papazoglou — Portfolio Website

A responsive static portfolio/CV website.

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static server.

Example:
```bash
python3 -m http.server 8080
```
Then visit `http://localhost:8080`.

## Deploy
This project can be deployed as-is to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static host.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive visual design
- `script.js` — reveal animations/year
- `Symeon_Papazoglou_CV.pdf` — downloadable CV
