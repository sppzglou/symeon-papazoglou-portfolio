PERSONAL PROJECT · KOTLIN MULTIPLATFORM

Orbit AI

A cross-platform personal AI assistant designed around natural conversation, streaming responses and native device actions. Orbit AI shares its core architecture across Android and iOS while still reaching platform capabilities such as alarms, calendar, contacts and app actions.

KotlinKotlin MultiplatformCompose MultiplatformKtor / KtorfitOllamaCoroutines & FlowKoin
01. OVERVIEW

One assistant,
native capabilities

I built Orbit AI as an end-to-end Kotlin Multiplatform project: shared domain/data layers, a Compose Multiplatform presentation layer, streaming LLM communication and platform-specific implementations where native APIs are the right tool. The assistant can interpret a request, decide when a tool is needed, execute that action on-device and keep the conversation flowing.

STREAMING AI

Responsive chat

Token-by-token responses are exposed as Kotlin Flow so the UI can update continuously instead of waiting for a full response.

TOOL CALLING

From text to action

Structured tool requests turn natural-language intent into native actions such as alarms, calendar events, contacts, calls, messages and app launching.

CROSS-PLATFORM

Shared where it matters

Business logic, networking, state and UI are shared, while Android and iOS implementations bridge into their own native capabilities.

02. ARCHITECTURE

Modular by design

The project is split into focused modules to keep platform code isolated from reusable logic. Use cases sit between presentation and repositories, while data sources handle local persistence and remote AI communication.

03. IMPLEMENTATION

What I focused on

The interesting part is not only sending prompts to an LLM. Orbit AI coordinates conversation context, tool schemas, streamed chunks, result/error handling and native execution while keeping those concerns testable and separated.

LLM LAYER

Ollama integration

A dedicated API and streaming client communicate with the local model, map DTOs to domain models and expose results through repository abstractions.

STATE

Predictable UI flow

Chat intents, state and effects keep user input, streaming output and tool execution coordinated without pushing platform details into the UI.

NATIVE BRIDGES

Platform-aware actions

Android and iOS have their own implementations for alarms, calendar, contacts, phone calls, messaging, voice input and application launching.
